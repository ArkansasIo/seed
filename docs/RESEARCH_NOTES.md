# Research Notes — Seed Engine
Native C++23 project for procedural game mathematics with a console client, backend server, local admin tool, and optional MySQL persistence.
Research domains: deterministic seed generation; galaxy/star-system/planet models; stat formulas; ship and character attributes; combat and economy simulation; user account roles; and relational storage.
Commercial game references are high-level inspiration only. No proprietary source, schema, or formula is claimed. Sample math is illustrative and requires balance tests.
Open questions: production MySQL version; authoritative server/client generation split; required replay determinism; first gameplay domain; expected users/worlds/tick rate.
